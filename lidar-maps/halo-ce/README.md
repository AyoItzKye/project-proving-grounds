# Halo: Combat Evolved LiDAR maps

## Author Provided Scans

The mod author's own scans of 18 Halo: CE maps in one zip: [lidar-maps-halo-ce.zip](https://github.com/AyoItzKye/project-proving-grounds/releases/download/lidar-maps/lidar-maps-halo-ce.zip) (1.1 MB, 2026-11-12).

Easiest: in the launcher, open **LiDAR scans**, choose Halo: CE and press **Import**. Or download the zip and choose it with **Import a shared zip ...** there.

Maps in it: beavercreek, bloodgulch, boardingaction, carousel, chillout, damnation, dangercanyon, deathisland, gephyrophobia, hangemhigh, icefields, infinity, longest, prisoner, ratrace, sidewinder, timberland, wizard.

## Player scans

Shared LiDAR scans of Halo: Combat Evolved maps, one zip per scan, named `<map>_<date>.zip` (the map's folder name, such as beavercreek, bloodgulch, hangemhigh).

To use one: download it and import it (see [the LiDAR maps page](../README.md)). It adds to your own scan of that map; it never replaces it.

No scans shared yet. Be the first: [share a LiDAR map](https://github.com/AyoItzKye/project-proving-grounds/issues/new?template=lidar_map.yml).
