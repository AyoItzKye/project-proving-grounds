# Halo 3: ODST LiDAR maps

## Author Provided Scans

The mod author's own scans of 8 Halo 3: ODST maps in one zip: [lidar-maps-halo-3-odst.zip](https://github.com/AyoItzKye/project-proving-grounds/releases/download/lidar-maps/lidar-maps-halo-3-odst.zip) (0.0 MB, 2026-11-12).

Easiest: in the launcher, open **LiDAR scans**, choose Halo 3: ODST and press **Import**. Or download the zip and choose it with **Import a shared zip ...** there.

Maps in it: odst_h100, odst_l200, odst_l300, odst_sc100, odst_sc110, odst_sc120, odst_sc130, odst_sc140.

## Player scans

Shared LiDAR scans of Halo 3: ODST maps, one zip per scan, named `<map>_<date>.zip` (the map's folder name, such as odst_h100).

To use one: download it and import it (see [the LiDAR maps page](../README.md)). It adds to your own scan of that map; it never replaces it.

No scans shared yet. Be the first: [share a LiDAR map](https://github.com/AyoItzKye/project-proving-grounds/issues/new?template=lidar_map.yml).
