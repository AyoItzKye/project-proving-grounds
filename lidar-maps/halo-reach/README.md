# Halo: Reach LiDAR maps

## Author Provided Scans

The mod author's own scans of 28 Halo: Reach maps in one zip: [lidar-maps-halo-reach.zip](https://github.com/AyoItzKye/project-proving-grounds/releases/download/lidar-maps/lidar-maps-halo-reach.zip) (1.8 MB, 2026-11-12).

Easiest: in the launcher, open **LiDAR scans**, choose Halo: Reach and press **Import**. Or download the zip and choose it with **Import a shared zip ...** there.

Maps in it: reach_20_sword_slayer, reach_30_settlement, reach_35_island, reach_45_aftship, reach_45_launch_station, reach_50_panopticon, reach_52_ivory_tower, reach_70_boneyard, reach_cex_beaver_creek, reach_cex_damnation, reach_cex_hangemhigh, reach_cex_headlong, reach_cex_prisoner, reach_cex_timberland, reach_condemned, reach_dlc_invasion, reach_dlc_medium, reach_dlc_slayer, reach_ff10_prototype, reach_ff20_courtyard, reach_ff30_waterfront, reach_ff45_corvette, reach_ff50_park, reach_ff60_airview, reach_ff60_icecave, reach_ff70_holdout, reach_forge_halo, reach_trainingpreserve.

## Player scans

Shared LiDAR scans of Halo: Reach maps, one zip per scan, named `<map>_<date>.zip` (the map's folder name, such as reach_20_sword_slayer, reach_70_boneyard).

To use one: download it and import it (see [the LiDAR maps page](../README.md)). It adds to your own scan of that map; it never replaces it.

No scans shared yet. Be the first: [share a LiDAR map](https://github.com/AyoItzKye/project-proving-grounds/issues/new?template=lidar_map.yml).
