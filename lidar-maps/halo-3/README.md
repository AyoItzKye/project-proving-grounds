# Halo 3 LiDAR maps

## Author Provided Scans

The mod author's own scans of 22 Halo 3 maps in one zip: [lidar-maps-halo-3.zip](https://github.com/AyoItzKye/project-proving-grounds/releases/download/lidar-maps/lidar-maps-halo-3.zip) (3.2 MB, 2026-11-12).

Easiest: in the launcher, open **LiDAR scans**, choose Halo 3 and press **Import**. Or download the zip and choose it with **Import a shared zip ...** there.

Maps in it: h3_armory, h3_chill, h3_chillout, h3_construct, h3_cyberdyne, h3_deadlock, h3_ghosttown, h3_guardian, h3_isolation, h3_lockout, h3_riverworld, h3_s3d_avalanche, h3_s3d_edge, h3_s3d_lockout, h3_s3d_powerhouse, h3_salvation, h3_sandbox, h3_shrine, h3_sidewinder, h3_snowbound, h3_spacecamp, h3_zanzibar.

## Player scans

Shared LiDAR scans of Halo 3 maps, one zip per scan, named `<map>_<date>.zip` (the map's folder name, such as h3_construct, h3_guardian).

To use one: download it and import it (see [the LiDAR maps page](../README.md)). It adds to your own scan of that map; it never replaces it.

No scans shared yet. Be the first: [share a LiDAR map](https://github.com/AyoItzKye/project-proving-grounds/issues/new?template=lidar_map.yml).
